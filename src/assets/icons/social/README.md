# 社交品牌图标

Gmail、QQ、X、小红书、Bilibili 和 GitHub SVG 来自 [Simple Icons](https://github.com/simple-icons/simple-icons/tree/d4e6ba93e48f178898707f0145ec285f28b64b38/icons)，固定来源提交 `d4e6ba93e48f178898707f0145ec285f28b64b38`。原始图标和 [CC0-1.0 许可](LICENSE.md) 保存在本目录。

用户要求使用对应平台图标；构建时由 Astro 内联为 SVG，沿用公共图标尺寸与 `currentColor`，不请求远程徽章图片。通用界面图标继续使用 Lucide。
