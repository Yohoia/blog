# 社交品牌图标

Gmail、QQ、X、小红书、Bilibili、GitHub、微信和 Telegram SVG 来自 [Simple Icons](https://github.com/simple-icons/simple-icons/tree/d4e6ba93e48f178898707f0145ec285f28b64b38/icons)，固定来源提交 `d4e6ba93e48f178898707f0145ec285f28b64b38`。原始图标和 [CC0-1.0 许可](LICENSE.md) 保存在本目录。

用户要求使用对应平台图标；构建时由 Astro 内联为 SVG，沿用公共图标尺寸与 `currentColor`，不请求远程徽章图片。通用界面图标继续使用 Lucide。

文章聊天菜单的 OpenAI 与 Claude 图标从 [Iconify Simple Icons 集合](https://icon-sets.iconify.design/simple-icons/) 获取，分别为 `simple-icons:openai` 和 `simple-icons:claude`，同样按 CC0 使用并在构建时本地内联。
